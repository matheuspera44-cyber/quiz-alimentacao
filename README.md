# Quiz – Alimentação Saudável ao Seu Alcance

Quiz interativo com 10 perguntas sobre educação alimentar.

## Como subir na Vercel

1. Acesse https://vercel.com e crie uma conta gratuita (pode entrar com o GitHub)
2. Clique em **"Add New Project"**
3. Escolha **"Upload"** (arraste a pasta do projeto ou faça o zip)
4. Clique em **Deploy**
5. Pronto! A Vercel gera um link público automaticamente.
